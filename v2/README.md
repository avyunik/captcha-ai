# Доведи, що ти людина! — CAPTCHA AI

Завершена локальна браузерна гра для студентського конкурсу «Логічні лабіринти». Капітан керує полем і демонструє екран у Discord/Google Meet. Реєстрація в сюжеті не є зовнішнім сервісом.

## Запуск і збирання

Потрібен Node.js 20.19+ або 22.12+ (перевірено Node 24), npm та сучасний браузер.

```sh
npm ci
npm run dev
```

Відкрийте адресу, яку покаже Vite. Команди:

```sh
npm test
npm run verify:levels
npm run build
npm run preview
```

Папка `dist/` після build — готовий статичний сайт. Її можна обслуговувати будь-яким HTTP-сервером. Не відкривайте `index.html` подвійним кліком через file://: ES-модулі потребують HTTP. Браузер не звертається до зовнішніх API/CDN; під час гри інтернет не потрібен, якщо сайт подано локальним сервером. Для першого встановлення npm потрібна мережа.

Готовий архів `CAPTCHA_AI_Game.zip` містить production-сайт: розпакуйте його й запустіть `python3 -m http.server 8000` у розпакованій папці. Відкрийте головну сторінку локального сервера. Програмувати або збирати його повторно не потрібно.

## GitHub Pages

Build використовує відносну базу `./`, тому підтримує підкаталог репозиторію. Спочатку злийте гілку гри в основну гілку репозиторію. У GitHub → Settings → Pages виберіть GitHub Actions, потім запустіть підготовлений workflow `Опублікувати гру`. Він виконує `npm ci`, тести, build та публікує лише `dist`. Увімкнення Pages і запуск публікації виконує власник репозиторію. Також можна завантажити вміст `dist` на довільний статичний хостинг вручну.

## Правила

Тренування 3×3 розв’язується центральною E. Воно не має таймера, ліміту або балів. Основний таймер починається після натискання «До основної гри».

Клавіша перемикає себе й ортогональних сусідів; мета — всі активні. Основні поля: 3×3, 4×4, 4×4, 5×5. Вони мають точні мінімальні рішення 3, 4, 6, 7 ходів та ліміти 5, 6, 9, 10. По 25 балів за рівень, максимум 100. Повторні спроби без штрафу. Undo повертає хід, reset відновлює початкове поле й починає нову спробу.

Пропущений рівень відкладається зі збереженням поля, історії та ходів. Після нових рівнів гра повертається до відкладених. Якщо інших невирішених рівнів немає, пропуск пропонує свідоме завершення або продовження. Бали нараховуються один раз, за статусом рівня.

Таймер 18 хвилин працює за абсолютним дедлайном, включно з попапами й фоновою вкладкою. F5 відновлює стан; прострочена сесія переходить до підсумків. При завершенні часу на попапі вже зароблені бали залишаються. Результат зберігається до підтвердженого нового старту. Не очищуйте дані браузера під час конкурсу.

Клавіші: миша, дотик або A–Y на фізичній клавіатурі з латинською розкладкою. Повтор keydown і швидке подвійне натискання блокуються. Тихі звуки Web Audio API можна вимкнути під екраном. Музики немає.

## Результат і PNG

Фінал містить команду, чотири статуси, оцінку, загальний час, кількість фактичних натискань за всі спроби та число спроб (без тренування). Undo не прибирає фактичне натискання зі статистики, але повертає доступний хід поточної спроби. Повне підтвердження й сюжетне розблокування реєстрації доступні лише за 100/100.

«Результати у PNG» справді завантажує кадр 1920×1080 з локальними шрифтами, ілюстраціями та даними. Кнопки керування не входять у PNG. Збережіть файл перед підтвердженням нової сесії. Перевірено завантаження та повне декодування п’яти PNG для всіх оцінок.

## Де змінювати

- `src/config.js`: тривалість, ключ зберігання, захист від подвійного вводу.
- `src/levels.js`: фіксовані поля, мінімальні кількості ходів та ліміти.
- `src/solver.js`: точний пошук мінімуму через усі варіанти першого рядка.
- `scripts/verify-levels.js`: перевірка й контрольні відповіді у `tests/level-answers.json` (для організатора, не показуються в інтерфейсі).
- `src/game-state.js`, `timer.js`, `scoring.js`, `storage.js`: переходи, час, оцінки та відновлення.
- `src/ui.js`: динамічний інтерфейс, модальні діалоги та п’ять завершень.
- `src/templates.js`: композиції, адаптовані з наданої галереї.
- `src/style.css`: додаткові стилі гри.
- `src/audio.js`, `export.js`: звук та справжній PNG-експорт.

Основні дані збережено в localStorage; це не серверний захист від навмисного редагування результатів. Для конкурсу викладач спостерігає за грою й фіксує PNG. На недоступному сховищі гра показує попередження; не закривайте таку вкладку.

Ціль — екран комп’ютера 16:9, перевірено 1920×1080 та 1280×720. Телефон підтримує дотик, але для читабельності потрібні горизонтальна орієнтація або масштабування; гра не видається за окремий мобільний дизайн.

Оригінальну галерею збережено в `public/assets/preview.html`. Її README/QA описують саме етап графіки, а цей README та `TEST_REPORT.md` — завершену гру. Архів асетів і попередні матеріали ZAZINO не змінено.

## Браузерні тести

`tests/browser.py` використовує Python, Playwright, Pillow та Chromium. У середовищі виконання ці залежності вже були встановлені. Для іншої машини встановіть `python3 -m pip install playwright Pillow`, браузер через `python3 -m playwright install chromium` і за потреби змініть шлях `executable_path` у тесті. Запустіть Vite, потім `python3 tests/browser.py`. Для готової збірки задайте `GAME_URL` адресою її локального сервера. Тести керують грою через кнопки, використовують контрольні рішення та окремо перевіряють відновлення після штучно простроченого дедлайну. Артефакти — `test-results/`.
